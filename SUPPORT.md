# Support

For template topology, the gateway, persistence and Railway deployment issues, open an issue in this repository. For the CMS itself (setup wizard, editor, plugins, themes, the REST API and MCP server), use the [EmDash project](https://github.com/emdash-cms/emdash) and its [documentation](https://docs.emdashcms.com). For the site framework, see [Astro](https://docs.astro.build).
